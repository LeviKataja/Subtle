    Proofreading

    A second pass that reads the whole translation at once and corrects only the lines that need it: mistranslated idioms, grammar slips, a name or term translated two ways. It runs after every translation unless you switch it off here; the estimates in the queue include it. The Proofread button on a file's review screen runs it again, with any model.

    Proofreading pays off when the reader is stronger than the translator: Haiku translating and Sonnet reading costs less than half of what Sonnet translating does. A reader weaker than the translator can undo good lines.

    Notifications

    The browser tab's title always says how far along the queue is. A notification can also tell you when it has finished.

    Cache

    Finished chunks are remembered, so repeating a file costs nothing.

    Automation

    Translate new downloads without being asked. Sonarr or Radarr report an import, Bazarr gets the first chance to find real subtitles, and whatever is still missing is translated and saved next to the video.

        Add the webhook by hand instead

        In each app: Settings → Connect → add a Webhook, method POST, with the import and upgrade triggers ticked. Then press its Test button; the test shows up under Recent activity below.

        These say “localhost” because that is how you opened this page. From another machine, use this computer's network address instead.
